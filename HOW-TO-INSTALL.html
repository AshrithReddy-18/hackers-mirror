How to Install

The Hacker's Mirror · PWA Installation Guide

🤖 Android (Chrome)
Recommended browser: Chrome or Edge
1
Open the app URL in Chrome on your Android phone
2
A banner will appear at the bottom saying "Install The Hacker's Mirror" — tap Install
3
If the banner doesn't appear: tap the ⋮ menu (top right) → tap "Add to Home screen"
4
The app icon appears on your home screen. Opens fullscreen, works offline ✓
✔ Works on Android 8+ with Chrome 73+. Also works on Samsung Internet and Edge.
🍎 iPhone / iPad (Safari)
Must use Safari — Chrome on iOS cannot install PWAs
1
Open the app URL in Safari (not Chrome) on your iPhone
2
Tap the Share button at the bottom of the screen (the box with an arrow pointing up ↑)
3
Scroll down in the share sheet and tap "Add to Home Screen"
4
Tap Add in the top right. The icon will appear on your home screen.
✔ Works on iOS 16.4+. On older iOS the app still works, but offline support is limited.
💻 Desktop (Chrome / Edge)
Optional — the app is designed for mobile but works on desktop too
1
Open the URL in Chrome or Edge
2
Look for the install icon ⊕ in the address bar (right side)
3
Click it → click Install. Opens as a standalone window.
🌐 Hosting (for sharing with others)
To share with others, you need to host these files online
1
Netlify Drop (easiest): go to app.netlify.com/drop and drag the entire folder — you'll get a live URL in 30 seconds. Free.
2
GitHub Pages: push the folder to a GitHub repo, enable Pages in settings. Free, custom domain supported.
3
Vercel: drag and drop or connect a GitHub repo at vercel.com. Free tier is generous.
⚠ PWA features (offline, install prompt) only work when served over HTTPS. All three options above provide HTTPS automatically.
